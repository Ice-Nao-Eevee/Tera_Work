Three independent, stateless helper modules under `lib/` with no internal dependencies between them except `coupon.ts` importing `formatRupiah` from `format.ts`. Each file is a flat collection of exported functions plus TypeScript interfaces: `coupon.ts` defines the `CouponData` shape and a discriminated-union `CouponValidationResult` for rule checking; `jwt.ts` wraps `jsonwebtoken` to sign/verify short-lived (`12h`) table tokens carrying `tableId`/`tableNumber`; `format.ts` exposes locale-aware number and date formatters. There are no classes, no framework bindings, and no runtime side effects — pure function libraries consumed by higher layers.
