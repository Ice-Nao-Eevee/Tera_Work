All files are React components consumed by the Next.js app shell. `ClientLayoutWrapper.tsx` is the composition root: it mounts `Header`, `Footer`, `AIChatPanel`, and `FloatingCart`, gates them behind a `/admin` pathname check, and wraps children in `ErrorBoundary`. `ErrorBoundary.tsx` is a class-based component that catches render errors and renders a branded fallback page. `Header.tsx` and `FloatingCart.tsx` subscribe to the shared store via `storeEvents.subscribe` from `@/lib/store` to stay in sync with cart/search state. `AIChatPanel.tsx` is an isolated slide-over panel that POSTs messages to `/api/chat` and renders a lightweight markdown subset inline. `Footer.tsx` is a static server component (no `'use client'`). Styling is exclusively Tailwind utility classes using the project's warm brown palette (`#b45309`, `#f3e8d6`, `#fcf8f2`, etc.), and icons come from `lucide-react`.
