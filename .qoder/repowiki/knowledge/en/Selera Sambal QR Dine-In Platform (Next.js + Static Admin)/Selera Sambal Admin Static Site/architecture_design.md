Single-page-style SPA built from plain HTML/CSS/JS with no build step. Each page (dashboard.html, products.html, orders.html, etc.) is a thin shell that loads `js/storage.js` then `js/app.js`; `app.js` reads `document.body.dataset.page` to dispatch to a per-route render function (`renderDashboard`, `renderProducts`, …) via an object map at line 216. All persistence goes through the shared `StorageManager` module in `storage.js`, which wraps `localStorage` under the `ss_admin_` prefix, provides defaults for `restaurant`/`settings`/`admin`, emits a `ss-data` CustomEvent on mutations, and supports backup/restore/reset. Authentication is local: `index.html` validates against the stored admin credentials and sets `ss_session` in sessionStorage plus an optional `ss_remember` flag in localStorage. The UI is composed by string-interpolated HTML fragments rendered into `#page`, with a global shell (`shell()`) injecting sidebar navigation, topbar breadcrumbs, and a quick-add button. CSS lives in `css/global.css`, `responsive.css`, and per-page sheets; there is no framework or bundler — the site is served as flat files.
