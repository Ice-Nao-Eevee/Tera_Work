Two frontends coexist under one workspace root with no separate npm packages: `nextjs_app` is the App Router customer experience backed by Prisma/Supabase/Mongoose against MongoDB, while `static_admin_site` is a frontend-only localStorage dashboard. They share tooling configured at the root — `tailwind.config.ts`, `postcss.config.js`, `tsconfig.json`, and `package.json` — so both apps consume the same Tailwind setup and TypeScript compiler options. The customer app persists to MongoDB through Prisma (`@prisma/client`) and Supabase auth helpers; the admin site has no server-side data layer and stores everything in `localStorage`. Root-level legacy HTML/CSS files (`Menu-list.html`, `Menu.html`, `html.html`, `css.css`, `global.css`) sit alongside the generated Next.js output as reference assets. Environment-driven configuration lives in `.env.local` with `MONGODB_URI` as the single switch between local MongoDB and Atlas.
