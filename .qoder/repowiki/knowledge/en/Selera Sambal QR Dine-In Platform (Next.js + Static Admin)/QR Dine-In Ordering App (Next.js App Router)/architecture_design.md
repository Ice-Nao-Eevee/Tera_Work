The module is organized along Next.js App Router boundaries: `app/` contains the page tree (`menu`, `cart`, `checkout`, `table/[tableId]`, `promo`, `order`, plus an `admin/` section) and the server-side REST surface under `app/api/<resource>/route.ts`. The root `app/layout.tsx` is the single entry point that injects global metadata, Tailwind theme, and wraps every page in `ClientLayoutWrapper` from `components/`. Cross-cutting concerns live in `lib/`: Prisma client (`prisma.ts`) and Supabase clients (`supabase.ts`, `supabaseAdmin.ts`) are the only DB access points consumed by both API routes and utilities; `types.ts` is the canonical TypeScript contract re-exported via `lib/models/index.ts`; `store.ts` provides a localStorage-backed cart/table session store with event-driven reactivity used by both public pages and admin. `utils/supabase/middleware.ts` supplies Next.js middleware for protecting `/api/admin/*` and `/admin/*` routes via JWT verification of the table token produced by `lib/jwt.ts`. All monetary values flowing through the API are recalculated server-side against the database to prevent price manipulation.
