`ClientLayoutWrapper.tsx` is the composition root: it mounts `Header`, `Footer`, `AIChatPanel`, and `FloatingCart`, gates them behind a `/admin` pathname check (`usePathname`) so admin pages render only an `ErrorBoundary`, and wraps children in `ErrorBoundary`. `ErrorBoundary.tsx` is a class-based component implementing `getDerivedStateFromError` / `componentDidCatch` to render a branded fallback page. Floating panels (`AIChatPanel`, `FloatingCart`) follow an `isOpen`/`onClose` prop contract and are conditionally rendered only after hydration via an `isMounted` flag. Cross-component state (cart items, search query) is read through `getCartItems()` / `searchEvents` and kept in sync via `storeEvents.subscribe` from `@/lib/store`, with subscriptions cleaned up in effect return functions. `AIChatPanel.tsx` is self-contained: it maintains local message history, posts to `/api/chat`, and renders a lightweight markdown subset (bold + bullet lists) inline. `Footer.tsx` is a static server component (no `'use client'`). The `admin/AnalyticsDashboard.tsx` sits under this directory but is not composed by the public shell.
