Two sibling frontends share the same workspace root: `nextjs_app` (App Router customer experience) and `static_admin_site` (localStorage-backed admin dashboard). They are not separate npm packages — they coexist under one `package.json`, so shared tooling (Tailwind via `tailwind.config.ts`, PostCSS via `postcss.config.js`, TypeScript via `tsconfig.json`) is configured once at the root. The customer app persists to MongoDB through Prisma (`@prisma/client`) and Supabase auth helpers; the admin site persists to localStorage only. Root-level HTML/CSS files (`Menu-list.html`, `Menu.html`, `html.html`, `css.css`, `global.css`) appear to be legacy or reference assets alongside the generated Next.js output. Environment-driven configuration lives in `.env.local` with `MONGODB_URI` as the single switch between local MongoDB and Atlas.
